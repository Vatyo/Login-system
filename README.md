# Login System 🔐

A Windows desktop application built with C# and WinForms featuring user authentication.

 ✨ Features
- User login form
- Create account functionality
- Welcome screen after successful login
- Input validation

🛠️ Tech Stack
- Language: C#
- Framework: Windows Forms (WinForms)
- IDE: Visual Studio 2022

 🚀 How to Run
1. Clone the repository
2. Open `.sln` file in Visual Studio 2022
3. Press F5 to run
